# 手動テスト手順 — サブ秒レンジ / フィルタ / 一括操作 / ダークモード

対象: `feature/2.0.2-batch`（拡張機能のみ。`apps/web` は対象外）
目的: 追加した4機能を、実際の d アニメストアのプレイヤーと拡張機能UIで確認する。

## 0. 準備

1. リポジトリ直下でビルドする（拡張機能だけ）。
   ```sh
   cd apps/extension
   bunx wxt build --browser chrome
   bunx wxt build --browser firefox
   ```
2. Chrome: `chrome://extensions` → デベロッパーモードON → 「パッケージ化されていない拡張機能を読み込む」→ `apps/extension/.output/chrome-mv3`。
   Firefox: `about:debugging#/runtime/this-firefox` → 「一時的なアドオンを読み込む」→ `apps/extension/.output/firefox-mv3/manifest.json`。
3. テスト用にプレイリストを2つ作る（例: `テストA`, `テストB`）。`テストA` に3件以上、`テストB` に1件以上入れる。
4. d アニメストアの作品ページからエピソードを開き、プレイヤー画面を表示する。

## 1. ダークモード（設定 → 外観）

- [ ] 管理画面（オプション）→ 設定 → 外観 で **ダーク** を選ぶ。
- [ ] 管理画面の背景・カード・入力欄・ボタンが暗色になり、文字が読める。
- [ ] ポップアップを開き、暗色で表示される。
- [ ] ポップアップ右上の月/太陽アイコン（SVG）ボタンでライト↔ダークが即座に切り替わる。
- [ ] もう一度ポップアップを開き直しても、選んだテーマが保持されている。
- [ ] 外観を **システム** に戻し、OSをダーク/ライトに切り替えると追従する。
- [ ] 外観を **ライト** にした状態でOSがダークでも、管理画面とポップアップはライトのまま。
- [ ] 共有プレイリストのインポート確認画面を開いた場合も、同じテーマで表示される。

## 2. サブ秒レンジ調整 + 試聴（A）

### 2-1. カスタム範囲バー
- [ ] プレイヤー画面で ♪ → 「カスタム範囲」を開く。
- [ ] 開始/終了の入力欄が `m:ss.s`（例 `1:23.4`）で表示される。
- [ ] `1:23.4` を入力すると `1:23.4` のまま確定する。
- [ ] `83.4`（秒のみ）を入力しても `1:23.4` になる。
- [ ] 各入力の横の `−` / `+` で 0.1 秒ずつ動く（切り替えなし）。
- [ ] 1 秒単位の調整は入力欄に直接 `1:23.4` のように書き換えて行う。
- [ ] 0 秒未満にならない（`−` が無効化される）。
- [ ] ウィンドウ幅を狭めると2行になるが、範囲・開始/終了・区間名・操作ボタンのまとまりは崩れない。
- [ ] 「テスト」で入力した範囲が再生される。

### 2-2. 追加モーダル
- [ ] ♪ の一覧から任意の区間を選び、プレイリスト追加モーダルを開く。
- [ ] モーダル上部に「開始値 `−` `+` - 終了値 `−` `+`」がラベルなしで並ぶ（他画面と同じ並び）。
- [ ] ステッパーで範囲を微調整すると表示が更新される。
- [ ] 「試聴」を押すとその範囲が再生され、**モーダルは閉じない**。
- [ ] 試聴中にもう一度ステッパーで調整 → 「試聴」を繰り返せる。
- [ ] 開始 ≧ 終了 の状態で「試聴」を押すと、モーダル内にエラーが出て閉じない。
- [ ] 「追加」で、微調整後の値がプレイリストに保存される。
- [ ] 保存後、管理画面の該当行の表示が `m:ss.s` になっている。

### 2-3. 管理画面の編集行
- [ ] 管理画面で「編集」を開く。
- [ ] 開始/終了欄が `m:ss.s` で表示される。
- [ ] ステッパーで調整 → 「保存」で値が更新される。
- [ ] 既存の秒表示（プレイリスト件数、一覧の `m:ss-m:ss` など）は従来どおり `m:ss` のまま。

## 3. フィルタ検索（B）

### 3-1. ポップアップ
- [ ] プレイリスト一覧の直上に検索欄がある。
- [ ] 作品名・エピソード名・プレイリスト名の一部を入力すると、該当アイテムを含むカードが自動展開される。
- [ ] 該当しないカードは折りたたまれる。
- [ ] Esc で検索欄が空になり、通常表示に戻る。

### 3-2. 管理画面
- [ ] プレイリスト一覧の先頭に検索欄がある。
- [ ] 検索語に一致しないアイテム行が非表示になる。
- [ ] 一致0件のプレイリストは折りたたまれる。
- [ ] Esc で検索が解除され、元の開閉状態に戻る。
- [ ] 追加モーダルには検索欄が増えていない。

## 4. 一括操作（C）

- [ ] 管理画面の各プレイリストヘッダーに「選択」がある。
- [ ] 「選択」ONで各行の先頭（ドラッグハンドルの左）にチェックボックスが出る。
- [ ] 選択ONのときだけ、コピー/削除の一括バーが出る（ボタンは2つだけ）。
- [ ] 1件以上チェックすると「N件選択」とコピー/削除が有効になる。
- [ ] コピー → コピー先選択 → 対象プレイリストに選択分が追加される。
- [ ] 削除 → 確認ダイアログに件数が出る → OKで選択分だけ消える。
- [ ] 選択した行のドラッグで、選択ブロックごと並び替わる（相対順序が保たれる）。
- [ ] 選択した行のドラッグハンドルで ↑/↓ を押すと、ブロック単位で1段ずつ動く。
- [ ] 別プレイリストへの移動はできない（コピー＋削除で代替）。
- [ ] 「選択」OFFで、チェックボックスと一括バーが消え、通常の行表示に戻る。

## 5. 回帰確認

- [ ] プレイリストの作成・名前変更・削除が従来どおり動く。
- [ ] 通常再生・シャッフル・前後移動が従来どおり動く。
- [ ] 共有（公開/更新/削除）とインポートが従来どおり動く。
- [ ] ブラウザの `alert` / `confirm` / `prompt` が一度も出ない。
- [ ] コンソールに新しいエラーが出ていない。
- [ ] 再読み込み後もプレイリスト・設定・テーマが保持されている。
