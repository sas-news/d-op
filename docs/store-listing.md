## Chrome Web Store

### 掲載情報

- **名前**: `d-OP`（変更不要）
- **簡単な説明**（132 文字まで）: 上記 manifest description と同文
- **詳細な説明**:

```text
d-OP は dアニメストア（animestore.docomo.ne.jp / anime.dmkt-sp.jp）の動画プレイヤーを拡張するブラウザ拡張機能です。

■ 主な機能
・OP/ED連続再生：各話のオープニング・エンディング範囲を検出してスキップし、シリーズを一気見しやすくします
・プレイリスト：劇中歌や好きなシーンをクリップとして集め、連続再生・シャッフル・並べ替えができます
・インポート/エクスポート：プレイリストをJSONでバックアップ・復元できます

■ 共有機能（バージョン2.0の新機能・任意）
作成したプレイリストを公開して、リンクで他の人と共有できます。
・「公開」と「限定公開」（リンクを知っている人だけが開ける）を選べます
・アカウント登録は不要です
・共有の利用には拡張機能内での明示的な同意が必要です。同意しない限り、外部へのデータ送信は一切ありません
・共有リストから自分だけのコピーを取り込んで編集（リミックス）できます

■ プライバシー
・通常利用は完全にブラウザ内で完結します。外部との通信は、共有機能を明示的に操作したときだけです
・詳しくはプライバシーポリシーをご覧ください
```

- **カテゴリ**: 現行のまま（機能上の変更なし）

### プライバシーに関する取り組み（宣誓タブ）

- **単一目的の説明**:
  「dアニメストアで OP/ED をスキップした連続再生と、好きなシーンのプレイリスト作成・管理（任意で公開・共有）を提供する拡張機能です。」

- **権限の使用理由**:

| 権限 | 記入文 |
|---|---|
| `storage` | 作成したプレイリスト・再生状態・設定・共有機能の同意状態をブラウザ内に保存するために使用します。 |
| `tabs` | プレイリスト連続再生用の再生ウィンドウ/タブを開き、1件の再生終了時に次の動画へ遷移するために使用します。既存タブの選択・フォーカス切り替えにも使用します。 |
| `animestore.docomo.ne.jp`、`anime.dmkt-sp.jp` | 中核機能のため必要です。dアニメストアの作品ページ・プレイヤーページ上で、OP/ED範囲の検出・スキップ再生・プレイリストへの追加UIを提供します。 |
| `d-op.sasnews.dev` | 任意の共有機能でのみ使用します。ユーザーが同意したうえで「公開」「取り込み」等を明示的に操作した場合に限り、このドメインのAPIと通信します。未同意の場合は一切通信しません。 |

- **リモートコードの使用**: 「いいえ」（全コードはパッケージ同梱）
- **データ収集の認証**: 共有機能はオプトイン。ユーザーが明示的に公開操作をした場合のみ、プレイリストの公開スナップショット（タイトル・説明・任意入力の公開者名・タグ・クリップ情報）を d-op.sasnews.dev に送信します。販売・第三者への提供・無関係な目的での利用・人間による閲覧は行いません。
- **限定使用の認証**: チェック（上記の通り）
